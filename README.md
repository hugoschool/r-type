# R-Type

A multi-threaded server and a graphical client for the "R-Type" game using a homemade game engine.

Fully made in **C++**, this project was realized in the `Software Architecture Engineering` module (G-ING-500) at Epitech. (Subjects available in [subject folder](./subject/))

Main repository url: https://github.com/hugoschool/r-type

## Building from source

Since this is mostly a C++ project, it uses CMake for compilation.

It can be easily compiled with these commands:
```sh
cmake -B build .
cmake --build build
```

## Download

You can download a released copy of the R-Type game in the [Releases tab](https://github.com/hugoschool/r-type/releases) on GitHub.

## Platform support

We only actively build & test for these platforms:

- Linux x86_64
- Windows x86_64
