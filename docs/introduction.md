# Introduction

A multi-threaded server and a graphical client for the "R-Type" game using a homemade game engine.

Fully made in **C++**, this project was realized in the `Software Architecture Engineering` module (G-ING-500) at Epitech.

Main repository url: https://github.com/hugoschool/r-type

## Download

You can download a released copy of the R-Type game in the [Releases tab](https://github.com/hugoschool/r-type/releases) on GitHub.
